# AH review protocol and implemented eligibility

Registration: PROSPERO CRD420261288537, version 1.0, 19 January 2026. The registered requirement for an objective severity or prognosis outcome was not applied as an obligatory eligibility criterion. The planned severity analysis could not be completed. Implemented eligibility permitted alpha-diversity or differential-abundance outcomes, with severity retained only as directional descriptions. This was a change during review conduct, not a prespecified amendment. The authors' written decision dated 18 July 2026 supports this explanation.

The publication window was January 2015 through December 2025. The exact execution dates of the three database searches are not documented in the available search records.
